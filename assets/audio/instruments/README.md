# Instrument Sound Files (Optional)

This directory is for different instrument versions of musical notes.
These are OPTIONAL - if not provided, the app will use the default notes from `/notes/` directory.

## File Naming Convention

For each instrument, create note files with the format: `{instrument}_{note}.ogg`

Example for piano:
- `piano_c.ogg`, `piano_d.ogg`, `piano_e.ogg`, `piano_f.ogg`, `piano_g.ogg`, `piano_a.ogg`, `piano_b.ogg`

Example for guitar:
- `guitar_c.ogg`, `guitar_d.ogg`, `guitar_e.ogg`, `guitar_f.ogg`, `guitar_g.ogg`, `guitar_a.ogg`, `guitar_b.ogg`

Example for flute:
- `flute_c.ogg`, `flute_d.ogg`, `flute_e.ogg`, `flute_f.ogg`, `flute_g.ogg`, `flute_a.ogg`, `flute_b.ogg`

## Supported Instruments

- piano
- guitar
- flute
- drum (use drum_hit.wav in /drums/ directory)

## Where to Get These Files

See the main README in `/assets/audio/README.md` for detailed instructions.

Best source: https://philharmonia.co.uk/resources/sound-samples/ (Free professional instrument samples)
