## כיצד ליצור את קבצי הסאונד?

### אפשרות 1: שירותי Text-to-Speech מקוונים
ניתן להשתמש בשירותים כמו:
- Google Text-to-Speech (בעברית)
- Amazon Polly (תומך בעברית)
- Microsoft Azure Speech (תומך בעברית)

### אפשרות 2: הקלטה ידנית
הקליטו את עצמכם או מישהו עם קול ברור וידידותי לילדים.

### אפשרות 3: ספריות חינמיות
חפשו בספריות סאונד חינמיות כמו:
- FreeSound.org
- OpenGameArt.org

## פורמט הקבצים
- **פורמט**: WAV (מומלץ לביצועים מיטביים)
- **Sample Rate**: 44100 Hz
- **Bit Depth**: 16-bit
- **Channels**: Mono או Stereo

## הערות חשובות
- הסאונדים צריכים להיות ברורים וידידותיים לילדים בני 2-6
- משך כל קובץ צריך להיות קצר (1-2 שניות לשם האות, 2-3 שניות להנחיה)
- הקפידו על איכות סאונד טובה ללא רעשי רקע
